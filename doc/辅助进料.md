# 辅助进料

打印过程中,耗材从料盘到热端要走很长一段。挤出机把料往里拉,阻力大时会打滑、挤出不足、
甚至把料拉细。辅助进料就是让 AMS 电机在挤出机吃力的时候帮着往里推一段,把这段路径的
张力卸掉。

## 和换料的区别

| | 换料 (change_filament) | 辅助进料 (Task1) |
| :--- | :--- | :--- |
| 触发 | 热床温度 = 通道号,且 gcode_state = PAUSE | 进料微动被压住,且 gcode_state = RUNNING/PREPARE |
| 通道 | 旧通道退 → 新通道进 | 只有当前通道 |
| 时长 | 由通道的 `load_time` / `uload_time` 决定 | 微动弹开就停,最多 `assist_pulse` 毫秒 |
| 优先级 | 高,持锁期间辅助进料让路 | 低,`try_lock` 抢不到就跳过 |

两者共用同一把每通道电机锁 `motor_lock`,不会同时驱动同一路 H 桥。

## 参数

参数都在 Web 主控制台,存在 NVS 里,掉电不丢。

| 键名 | 默认 | 说明 |
| :--- | :--- | :--- |
| `assist_enable` | false | 总开关。默认关,先手动验证再开 |
| `assist_pulse` | 400 | 单次推送上限(ms)。微动中途弹开会更早停 |
| `assist_gap` | 150 | 两次推送之间最小间隔(ms)。压住不放时的占空比 = pulse/(pulse+gap) |
| `assist_dbnc` | 3 | 去抖采样次数,每次 10ms。连续 3 次读到低电平才认 |
| `assist_limit` | 15000 | 5 秒窗口内累计推送上限(ms)。超了自动关闭开关并报警 |

## 接线

微动开关接 `forward_click`,默认 **GPIO7**,内部上拉,另一端接 GND。

- 微动**未被压**:GPIO7 读到高电平(上拉)
- 微动**被压**:GPIO7 读到低电平 → 认定料被拉紧 → 推料

如果实际机械方向相反(压住代表料松),把 Task1 里两处 `gpio_get_level(...) != 0` /
`== 0` 反过来,或者改接微动的常开/常闭端。

## 硬件限制(重要)

当前电机驱动是 GPIO 直驱 H 桥,**没有 PWM/EN 脚**:

- 电机只有"正转/反转/停"三态,**不能调速**
- 没有编码器,**没有闭环**
- 只有一个单点微动,**没有缓冲位移量**

所以辅助进料只能是 **bang-bang 脉冲**:压住就推,弹开就停,靠 `pulse`/`gap` 的占空比
近似平均送料速度。想要真正的恒张力,需要给 H 桥加 EN/PWM 脚并改 `motor_jog` 用
`ledc` 输出,或者换成带编码器的步进方案。

## 调参建议

1. 先用"手动送料"按钮确认方向正确、料确实在往热端走
2. `assist_pulse` 从 300 起,听电机声音:如果每推一次都能听到明显的"顶住"声,说明推多了,往下调
3. `assist_gap` 太小(N20 空转电流小,但堵转发热)建议不低于 100
4. 软料(TPU)建议直接关掉:挤出机本身打滑时辅助进料会把料推弯在热端上方

## 安全逻辑

- 只在 `gcode_state` 为 RUNNING / PREPARE 时动作,空闲和结束一律不推料
- 打印状态超过 60 秒没更新(通常是 MQTT 掉线)一律停手
- 当前通道为 0(无耗材)时不动作
- 5 秒内累计推送超过 `assist_limit` 就自动关闭开关,防止微动粘连/线松了导致电机无限推料
